# peng (mimo.c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pure-C engine (`c/mimo.c`) that runs MiMo-V2.5 with colibrì's expert-streaming technology, validated token-exact against the official `transformers` implementation.

**Architecture:** Sibling engine cloned from `c/glm.c` (precedent: `c/olmoe.c`). Reused untouched: safetensors reader, quant kernels, expert streaming/LRU, sigmoid noaux_tc router, sampling. Replaced: MLA+DSA attention → fused-QKV GQA with partial non-interleaved RoPE, hybrid full/SWA-128 masking, per-head SWA sink bias, V×0.707. Removed: shared expert, MTP, DSA, KV persistence.

**Tech Stack:** C11 + OpenMP + AVX2 (existing kernels), Python only for the oracle/converter (torch, transformers, safetensors).

**Reference facts** (verified 2026-07-10 against raw `config.json` and `modeling_mimo_v2.py`; see spec `docs/superpowers/specs/2026-07-10-peng-mimo-design.md`):
- 48 layers; `hybrid_layer_pattern[i]==0` → full attention (indices 0,5,11,17,23,29,35,41,47), `==1` → SWA-128. `moe_layer_freq[i]==0` → dense MLP (only layer 0).
- Full layers: 64 Q / 4 KV heads; SWA layers: 64 Q / 8 KV heads. head_dim 192, v_head_dim 128.
- RoPE: non-interleaved (rotate_half), first `rope_dim = int(head_dim*0.334) = 64` dims only; theta 1e7 (full) / 1e4 (SWA); scaling `1/sqrt(192)`.
- Fused `qkv_proj` [q_size+k_size+v_size, 4096]; `o_proj` [4096, 64*128] separate, bias-free everywhere.
- SWA layers add a per-Q-head `attention_sink_bias` logit to the softmax denominator.
- V multiplied by `attention_value_scale = 0.707` after projection (runtime).
- Router identical to GLM-5.2: sigmoid → +e_score_correction_bias for selection → top-8 → weights from raw scores → normalize → ×1.0.
- Working directory for all commands: `C:\colibri` on Windows, `~/colibri` inside WSL (`wsl -d Ubuntu-24.04`). Every commit is also pushed: `git push peng peng`.

```python
"""Tiny random MiMoV2 oracle: real architecture, minuscule dims.
Saves weights+config to c/mimo_tiny/ and greedy/TF reference to c/ref_mimo.json."""
import json, sys, torch
sys.path.insert(0, "tools")
from mimo_ref.configuration_mimo_v2 import MiMoV2Config
from mimo_ref.modeling_mimo_v2 import MiMoV2ForCausalLM

torch.manual_seed(1234)

cfg = MiMoV2Config(
    vocab_size=256, hidden_size=128, intermediate_size=64,
    num_hidden_layers=6, num_attention_heads=8, num_key_value_heads=2,
    head_dim=24, v_head_dim=16, partial_rotary_factor=0.334,   # rope_dim = 8, even
    rope_theta=10000000.0, swa_rope_theta=10000.0,
    sliding_window=8,
    hybrid_layer_pattern=[0,1,1,0,1,1],       # full at 0 and 3, SWA elsewhere
    moe_layer_freq=[0,1,1,1,1,1],             # layer 0 dense
    n_routed_experts=8, num_experts_per_tok=2, moe_intermediate_size=32,
    n_group=1, topk_group=1, norm_topk_prob=True, routed_scaling_factor=None,
    attention_projection_layout="fused_qkv",
    add_full_attention_sink_bias=False, add_swa_attention_sink_bias=True,
    attention_value_scale=0.707,
    swa_num_attention_heads=8, swa_num_key_value_heads=4,
    attention_bias=False, layernorm_epsilon=1e-5,
    max_position_embeddings=4096, tie_word_embeddings=False,
)
cfg._attn_implementation = "eager"
model = MiMoV2ForCausalLM(cfg).eval()
with torch.no_grad():
    for n, p in model.named_parameters():
        if p.dim() >= 2:
            p.normal_(0, 0.05)
    for layer in model.model.layers:
        if hasattr(layer.mlp, "gate"):
            layer.mlp.gate.e_score_correction_bias.copy_(
                torch.linspace(-0.1, 0.1, cfg.n_routed_experts))
        if getattr(layer.self_attn, "attention_sink_bias", None) is not None:
            layer.self_attn.attention_sink_bias.copy_(
                torch.linspace(-0.5, 0.5, layer.self_attn.num_attention_heads))

print("=== state_dict tensors (names for the C loader) ===")
for n, p in model.state_dict().items():
    print(f"  {n:60s} {tuple(p.shape)}")

prompt = [3, 14, 159, 26, 53, 58, 200, 11, 77, 240, 5, 99]
ids = torch.tensor([prompt])
with torch.no_grad():
    out = model.generate(ids, max_new_tokens=20, do_sample=False, use_cache=True)
full = out[0].tolist()
with torch.no_grad():
    lg = model(torch.tensor([full]), use_cache=False).logits[0]
tf_pred = lg.argmax(-1).tolist()
print("full  :", full)
print("tf_pred:", tf_pred)

model.save_pretrained("mimo_tiny", safe_serialization=True)
json.dump(cfg.to_dict(), open("mimo_tiny/config.json", "w"))
json.dump({"prompt_ids": prompt, "full_ids": full, "tf_pred": tf_pred},
          open("ref_mimo.json", "w"))
print("saved: mimo_tiny/ + ref_mimo.json")
```

### Task 5: GQA attention with hybrid masking

**Files:**
- Modify: `c/mimo.c` — replace the `attention()` stub, rewrite `kv_alloc`

- [ ] **Step 1: KV cache members in `Model`.** Replace MLA's `float **Lc, **Rc` with:

```c
float **K, **V;   /* per layer: K [max_t * kvh*head_dim], V [max_t * kvh*v_head_dim] */
```
`kv_alloc(m, max_t)`: per layer `kvh` from layer type (v1: linear full-length for every layer; the SWA ring is a post-validation optimization).

- [ ] **Step 2: Non-interleaved partial RoPE**

```c
/* NeoX-style su i primi rope_dim del head: [a|b] -> [a*cos - b*sin | b*cos + a*sin] */
static void rope_neox(float *h, int pos, int rope_dim, float theta){
    int half = rope_dim/2;
    for(int j=0;j<half;j++){
        float inv = powf(theta, -2.0f*j/rope_dim);
        float ang = pos*inv, cs=cosf(ang), sn=sinf(ang);
        float a=h[j], b=h[half+j];
        h[j]      = a*cs - b*sn;
        h[half+j] = b*cs + a*sn;
    }
}
```
Applied per head to the FIRST `rope_dim` dims of q (each of the 64 Q heads) and k (each KV head); the remaining `head_dim - rope_dim` dims pass through. Theta per layer: `c->is_swa[li] ? c->theta_swa : c->theta_full`.

- [ ] **Step 3: `attention()` body.** Signature stays `(Model*, Layer*, int layer, float *x, int S, int pos_base, float *out)`. Per position s (parallel over heads like glm.c):

```
kvh   = is_swa ? kv_heads_swa : kv_heads_full
group = n_heads / kvh                          /* 16 (full) o 8 (SWA) */
qkv   = matmul_qt(L->qkv, xnorm)               /* [S, qs+ks+vs] */
split → q [n_heads*head_dim], k [kvh*head_dim], v [kvh*v_head_dim]
v    *= c->v_scale                             /* 0.707 */
rope_neox su q (per head) e k (per kv-head)
append k,v alla KV del layer a pos_base+s
lo    = pos_base+s < win ? 0 : pos_base+s-win+1   se SWA (win=sliding_window), altrimenti 0
per head h (kv-head g = h/group):
    logits[t] = dot(q_h, K[t,g]) * attn_scale     per t in [lo, pos_base+s]
    softmax con sink opzionale:
        M = max(max_t logits[t], sink ? L->sink[h] : -inf)
        den = Σ exp(logits[t]-M) + (sink ? exp(L->sink[h]-M) : 0)
        p[t] = exp(logits[t]-M)/den                /* la colonna sink si scarta */
    ctx_h = Σ_t p[t] * V[t,g]                      /* [v_head_dim] */
out = matmul_qt(L->o, concat(ctx))                 /* [S, hidden] */
```
The sink math is exactly `eager_attention_forward` lines 89–97 of the reference: concat sink logit, softmax, drop.
